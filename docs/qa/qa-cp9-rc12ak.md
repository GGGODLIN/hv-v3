# 修正王戰數據（2026-10-30，Asia/Taipei；腳本 /workspace/ak_boss_fix.py）
## 算法
- 資料：qa-saves/rc12ak-{blade,bulwark,oc,arcane}{1,2,3}-end.json 的 turnlog（欄位 runId、lean、floor、level、turn、bossDmg、bossHp、bossMaxHp；只有王戰列）。turnlog 跨局串接，每檔只取**最後一列的 runId** 的列（並檢查 lean 與檔名一致）。
- 一場王戰＝該 runId 下同一 floor 的列。回合數＝max(turn)+1（turn 由 0 起算）。bw3 F55 有一個 turn 16 重複列（推測重新載入），回合數記 23，兩列傷害都計入（每列 bossDmg 都是當列王 HP 實際下降）。
