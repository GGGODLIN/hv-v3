## 推測
- oc 的死亡應該來自整局消耗（藥水、HP 帶入下一層），單場 boss 重播量不到這種消耗。
- 可選方向：
  - (a) 給 oc 開深層曲線（SIM_DEEP_OC）；
  - (b) 整局的藥水或經濟壓力；
  - (c) 提高 oc 專屬的 bossAtk 上限。
