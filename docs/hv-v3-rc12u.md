# hv-v3 rc12u（所有新數值皆為 自訂，非原版）

## 診斷（scripts/rc12u-bossdiag.ts 逐回合紀錄）
- 堅盾 F35–65 王本體 HP 已很小（1.9k–5.3k，刀約 7.5k–22.7k）。
- 王戰中的小怪 94–100% 回合存活，54–57% 回合的傷害打在小怪身上。
- 小怪繼承了一般戰的 mob12m HP 層（堅盾 mobHp ×21，rc12t 提高），所以王 HP ×0.3 沒有效果。
- 修正（自訂）：`RUN12U.addHpK = 0`，王戰小怪不再吃 mob12m HP 層。修正後王戰縮到 5–6.5 回合，所以把 `bwBossHp` 從 0.3 調回 0.5（F100 端點 bwBoss100 仍為 0.3）。

## 變更（自訂）
- 一般戰勝利補血：額外項 `winHealNormal` 0.1→0.2，加上 winHeal 共 30% max HP。註：rc12t 程式碼原本就是 10%+10%=20%，QA 觀察只有 +10%，這部分需要製作人確認。
- 菁英戰勝利自 F15 起給 1 瓶藥水（`RUN12U.elitePot` / `elitePotFrom`）。
- R12O_BASE 各流派：
  - blade：deepK 12→55，bossHp70 0.2→0.4
  - bulwark：mobHp 21→1.5，deepK 30→60
  - oc：mobHp/mobDmg 5/5→2/7
  - arcane：deepK 18，DEEP12G.hpS.arcane 0.05
- 王 HP 倍率沒有再調低。potS 維持 6，遵守 rc12k 製作人訂的 +6 上限。
