# hv-v3 rc12ah（未達標：不打 tag、不部署）

## 已驗證
- **3 防禦淨 HP**：rc12ag 的 A/B 只扣「最大一隻蓄力怪」的防禦一擊，漏了同回合的其他怪（QA ar1 F25T1：塔主 160 + 蓄力怪 146 = 306，面板只算 262）。B 也沒有用最低擲骰。新的 `defNet12ah`：
  A = min(maxHp, hp+h) − 全體防禦傷害的「最高擲骰暴擊」總和，B = min(maxHp, hp+h) − ⌊全體防禦、不暴擊 × ROLL_MIN⌋。
  probe（scripts/rc12ah-defprobe.ts，128 seeds，只算按 D 的蓄力回合）：實際 HP 低於 A 的比例 blade/bulwark/oc/arcane 是 0/0/0/0%，舊 A 是 21/44/33/30%。
  實際高於 B 的比例是 12/21/39/14%，原因是閃避、格擋、擊殺或暈眩，面板另有文字提醒。
- **4 arcane F65 首領戰 p90**：23 → 19。改動是 `RUN12AH.bossK.arcane = 0.85`（**自訂**），作用在 F60–69 的首領 HP。
- **1 藥水**：sim 與實玩的 F60 開場藥水中位數相近。實玩以未到達算 0：bl 8 / bw 5 / oc 8 / ar 4；sim 是 8 / 7 / 8.5 / 5。
  兩邊起始都是 13 瓶，F50 約 10–12 瓶，喝藥時的 HP% 中位都在 21–31%。實玩 F45–59 的勝場收入是：首領 35 場拿 35 瓶，一般戰 68 場拿 8 瓶，寶箱 0 瓶，商人 0 次購買。
  差別在低尾：實玩有 0、1、2 瓶的局，這些局都伴隨長戰。現有 sim 的中位數已經 ≥3，**所以沒有加藥水**。
  試過 bw/oc/ar 的 F45–69 首領各 +1 瓶，結果樓層中位升到 82/83，超過 72。
- **2 oc F58–66 一般戰**：中位 18（≤20，達標），最大 37（>30，未達標）。

## 推測
- 實玩 node 事件的藥水數會把同一場戰鬥裡的喝藥與收入互相抵銷。所以用 node 推出的收入（中位約 2）偏低，不代表真正收入偏低。
- oc 長尾來自防禦循環，不是怪的 HP。r1–r3 把 oc 的 mobK 斜坡提前，最大值仍是 36–37，而樓層中位升到 73–76。
