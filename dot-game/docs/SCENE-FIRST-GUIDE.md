# 戰場優先的介面候選

這是回應「像管理後台、畫面太有模板感」的結構調整，不是新增戰鬥機制，也不是已驗收發布的換皮版本。

## 先看戰場，再找工具

- 以緊湊狀態列呈現角色等級、生命、魔力、成長、現用武器與既有資源；進度控制權／相容模式訊息不再放在長頁最底部。
- 寬畫面改為戰場主區與背包側區，不再讓人物立繪、戰場與說明各佔一欄。移除主畫面的多邊形人物肖像與重複英文眉標，使用較克制的實色邊框。
- 遠征路線、開始遠征、藥水、通關後回營與立即回營緊接場景，先於敵方詳細說明與戰術規則。出征門檻、藥水庫存、試煉種子不退等動作相關提示仍保留。
- 三個已穿裝備比較按鈕與背包篩選焦點退路仍在可見區域，不為了縮短版面而放入預設隱藏的工具分頁。
- 戰術與詳細路線規則使用原生可展開區域；展開／收起只改視圖，不會暫停戰鬥、套用設定、替你選裝或花費資源。
- 窄畫面按角色狀態、場景、主操作、背包／裝備、工具的閱讀順序排列。不用左右滑動的面板取代主操作。

## 素材不是這次已完成的部分

使用者分享的 X 貼文開啟回傳 403，素材名稱、原始下載位置與授權尚未確認。沒有重試鏡像、猜素材包、下載或匯入不明素材；沒有把其他作者的像素圖加入本作。現有獨立 canvas 圖像及文字裝備標記只是暫用，不代表使用者分享的素材或最終美術方向。

有辨識度的道具圖格、角色與敵人統一像素比例，待可核實的素材來源及授權到位後再做，不以更多裝飾圖塊掩蓋資訊層級問題。

## 安全與驗收界線

角色生命、魔力、模式、存檔與進度控制權不因收起規則而消失。錯誤／舊版存檔保護可擴高頁首，不截斷警告來湊首屏高度。出售、綁定、裝備界與配裝仍用原有預覽及確認流程；不改選取、持有權、費用、取消或舊確認失效規則。
