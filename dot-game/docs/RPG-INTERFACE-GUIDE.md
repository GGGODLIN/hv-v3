# v0.32：場景、裝備槽與比較使用同一套介面

這次不新增玩法。最新使用者回饋要求減少管理後台與模板感；使用明確授權元件，把資訊組織與美術辨識真正落到程式，而不是再寫一份風格提案。

## 本次改動

1. **共同材質與字級。**深板岩底、低飽和暖色主要按鈕、薄分隔線；不混用 Kenney 五種色組，不再增加玻璃卡片與金色裝飾。繁中字型仍採系統 CJK 字族，不載入包內無中文的字型。
2. **裝備槽，而非字元圖示。**六種獨立 SVG 搭配 Kenney 重色凹槽；目前三件裝備另列，背包為同寬圖格。名稱完整換行、不限成一行省略，品質／等級／綁定／IW 仍為文字。圖示裝飾性空 alt，不重複朗讀。
3. **查看與選售分開。**圖格按鈕只比較，獨立原生 checkbox 才選售。視覺及 DOM 順序皆為查看後選售，不使用容器反向排列造成鍵盤順序錯位。隱藏選取與完整確切 ID 出售確認不改。
4. **比較緊接背包。**選取圖示、名稱、現穿 → 選取數值、正負差值、換裝／鎖定／出售依序呈現。比較在批次出售與安全整理區之前，不再被整理說明埋在底下。無 sticky、浮動抽屜或 hover-only 才能看見的內容。
5. **戰場仍是主角。**保留 v0.31 薄角色狀態、場景下方主要操作及次要規則展開區。兩欄寬畫面、單欄窄畫面；各圖格與文字允許自然增高，不為滿足首屏而裁掉風險／錯誤訊息。

## 不改的界線

`engine.js`、`loot.js`、`session.js`、42 個歷史 fixture 完全不改。沒有新增存檔欄位、亂數、掉落、價格、出售策略、預設政策、戰鬥公式、鎖定規則、綁定／IW 資格、待領 FIFO 或權限。比較仍追蹤確切 ID，重畫時只復原原本真的有焦點的比較按鈕；不把焦點拉去新圖示。已穿選取新增 `aria-pressed` 與清楚邊框；按鈕 focus-visible 使用外圈，不只靠稀有度色彩。

## 驗收界線

已有靜態 SVG 真實像素檢視、來源測試與 JSDOM 控制器／引擎重播。**尚未實際瀏覽器畫面、CSS 排版、Tab 可見焦點、窄螢幕或觸控驗收；未發布。**不能從測試數量推論畫面漂亮，也沒有聲稱使用者已看見新版。原本 canvas 角色／場景仍暫用，尚未完成全遊戲美術一致化。正式網站仍為已驗收 v0.25。
