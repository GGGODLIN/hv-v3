## 本次新增檢查

`tests/scene-first-audit.test.mjs` 共 **15 項通過**。以實際 HTML 祖先結構執行完整 UI 控制器，另加原焦點測試 helper 沒有涵蓋的「關閉原生 details」可見性判斷。此判斷只檢查祖先語意，不是瀏覽器計算樣式或像素可見性。

- 營地、戰鬥、戰敗中輪流切換三個工具分頁，HP／MP、模式、資源、控制權與主要操作仍在已呈現結構內；切分頁不改遊戲、RNG 或寫入。
- 唯讀狀態仍顯示「不寫入存檔」與控制權資訊；即使直接呼叫過期的主要操作事件，仍不能變更進度或寫入。這是控制器權限邊界，**不是實際跨分頁 Web Locks 驗收**。
- 不支援的存檔保持覆寫保護，警告在工具外；測試區分正常偏好設定寫入與被禁止的 `save-v3` 進度寫入。
- 原生 `details` 第一個直接子元素為有文字的 `summary`，沒有巢狀互動控制；靜態 ARIA 參照全部唯一存在。營地方向鍵／Home／End 維持單一 tab stop，焦點停在可見分頁。
- 已穿三件裝備保持可比較；重畫後確切 ID 焦點不丟失。背包換入已穿位置、移除物品退回可見篩選、清除篩選與待領移入背包均保留可見目標，不需自動打開另一工具分頁。
- 自選出售仍列出篩選外物品，操作旁警告未收起；取消不花費，返回原控制焦點。控制權喪失會使已開啟確認失效，未出售原因仍在對話框中。
- 永久綁定與 Item World 的完整費用、不可逆／撤退損失說明保持在當次操作對話框，未藏進次級說明。綁定預覽取消不扣碎片；IW 確認後只扣一顆種子，焦點回到可見撤退控制，種子不退警告可讀。

這些測試使用明確標示的有效受控 fixture 及公開物品建立函式；不冒充自然取得、勝率或瀏覽器遊玩證據。
