# 待領戰利品：來源實玩與回收驗證

本文件是 Node 來源引擎模擬，不是瀏覽器實玩、正式發布或原版 HV 的掉落頻率結論。公開候選／網站仍未操作。

## 事先固定的範圍

- 已發現的 seed42 是明確標示的重現案例，不包裝成獨立隨機驗證。另固定 seed29、77，每個最多400次普通遠征；首次產生待領裝備即停止。保留沒有溢出、戰敗或單場1,000個 pulse 上限的結果，不繼續挑有利 seed。
- 從新角色開始，固定第1路線、均衡與預設設定。前10次出發前，依現有分數選各部位最高的已取得裝備（同分取較後項）；這是測量用配裝程序，不是推薦最佳配裝。沒有 AP、手動藥水、委託、自動出售、RNG／屬性／資源注入。
- 每次出發前，若背包超過115件，逐件明確出售最早的未鎖定裝備，直到115件；每場請求「通關後回營」，以1秒 pulse 推進。引擎仍以內部分步結算，不模擬離線收益。
- 投資分支從第11次出發前起，使用自然賺得的100碎片，確認綁定第一把符合資格的背包武器，不裝備它，也不追加 IW；追蹤同一 ID、鎖定與不可變綁定錨點。seed42另保留不綁定的原重現分支，逐場戰況／RNG摘要雜湊必須相同。

此界線於執行本測量前固定。腳本、精確輸入 SHA256、每場狀態串流雜湊與首個溢出物件保存在單一緊湊 JSON；可以從種子與公開動作重跑，無需大量分片或私有瀏覽器存檔。

## 自然狀態與構造狀態分開

自然溢出：完整120格背包與待領裝備。檢查滿包「領取」不動任何狀態，再以完整報價明確出售一件普通裝備，沿用既有 FIFO 自動補入，核對只有選售 ID 消失、金幣正確、其他物件／綁定錨點／碎片／種子／RNG不變；繼續明確清到115件並成功再出發。

自由空間待領：當前自然動作不會產生「有空位但待領未補入」；這是既有 v3 讀者接受並保留的資料分布。測量另取自然取得的出發前營地快照，只把同一把已賺得且綁定的背包武器移至待領區，不新增、刪除或改造裝備，也不變更資源。先經原存檔驗證，再執行新的營地領取。必須只變更兩個容器，保留原物件引用、所有持有物件內容與非背包狀態，重複領取不生效，重載仍保留。**這是明確構造的支持狀態驗證，不冒稱自然遊玩發現死鎖。**

合計1,430場普通勝利／12,267個1秒 pulse，沒有戰敗或單場上限截斷。三個投資分支合計1,115勝；seed42兩分支是同一種子的對照，不能當獨立母體。seed29／77沒有出現待領，不能因此聲稱日常必定發生、永不發生或估計可靠頻率。

- seed42待領物件是 `loot-556`「普通・餘燼護衣」（Average護甲）。最後獎勵訊息現在明確寫保留於待領區，不再誤稱已入背包。裝備與 RNG 本身沒變。
- 三分支都在第11次出發前，花自然賺得的100碎片綁定背包武器：seed42 `loot-3` Exquisite、seed29 `loot-2` Exquisite、seed77 `loot-1` Average。未換上它們；其原Lv3綁定錨點在成長至Lv31／33後仍逐次相同。seed42未綁定／綁定的完整逐場戰況、RNG與報告串流雜湊一致，不表示其他投資或配裝普遍不影響戰鬥。
- 自然滿包恢復：滿包領取完整no-op；明確出售 `loot-440` 得25金幣，`loot-556`依既有FIFO補入。再明確出售 `loot-441`～`loot-445`，最終115背包／0待領，金幣50,125→50,480，碎片3,050／種子315不變；同一綁定武器和錨點保留，成功再次出發。沒有自動挑選出售政策加入遊戲。
- 三個**構造的支持狀態**各取最後一次出發前115件營地快照，僅把已取得的綁定武器移到待領，形成114背包＋1待領。存檔先驗證通過，再領回同一物件，回到115＋0；所有持有物件的內容、非背包狀態、資源與 RNG 完全保留。重複領取不動作、重載保留；沒有聲稱121件能全部塞進120格。

### 與 exact v0.27 的逐步比較

四個來源分支均在每次公開動作及每個 pulse 後，對照來源 commit `6cb7230093f0ddc99bdddd0c1d96efabf4aa8d4b` 的完整引擎狀態及全部遠征報告，共**17,178次完整比較通過**。只允許把新「保底裝備已保留於待領區」訊息正規化回舊「保底裝備已入背包」；沒有排除其他欄位。RNG、物件、裝備、待領、英雄、資源、時鐘、事件及戰況都精確相同。新手動領取只在上述獨立構造分支執行，不混入普通戰鬥一致性宣稱。

基準引擎 SHA256：`76750a0da6b2ecf4a0e61ce0a99bc1c166f76a53ea744098f8f03fe5074b0ffd`。基準同目錄的 `loot.js` 必須與本次未改的 loot 一致；腳本會核對兩者，不需複製110KB新 fixture。當前引擎／loot／腳本的精確雜湊、首個待領物件與全部摘要見 [`measurements/pending-loot-v028.json`](measurements/pending-loot-v028.json)，單檔約16KB。沒有重寫任何既有fixture。
