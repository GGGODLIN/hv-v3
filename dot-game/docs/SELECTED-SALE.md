# v0.12 自選批次出售

背包整理新增「自己逐件選、一次確認出售」。這是本作的便利操作，不是原版 HV 的自動判裝規則。原版有裝備出售與信用點經濟；本作既有售價、掉落、品質模型及容量都不變。

## 怎麼用

回營後逐件勾選要賣的未鎖定背包物品，再開啟出售預覽。預覽列出精確 ID、名稱、品質、每件售價、合計，以及相對當前同部位裝備的六項屬性差異。確認前不會出售；取消不扣物品、不加金幣。鎖定與已裝備物品不能選入。

這不是「預覽安全整理」：你可主動選擇出售高品質、有取捨或更強的裝備。系統不會按評分幫你選，也不保證選中的都比較差。武器特效、不同基底及配裝用途不能用總分取代。請保留想留的備用裝備；出售沒有遊戲內復原，重要進度請先匯出。

篩選與排序不改變物品 ID。已選物品即使不在目前篩選中，也必須在確認清單中完整顯示。清空選取只清除暫存選擇，不刪裝備。選擇與確認不寫入存檔，重新載入、匯入或分頁重新同步後不沿用。

## 一次確認只代表這份清單

引擎重新核對精確物品資料、鎖定狀態、比較裝備及金幣／報價條件；任何失效都整批拒絕，不先賣一部分、不自動補入別件。重複確認不能重複收款。戰鬥與唯讀分頁不能執行；切換控制權後需重新選擇／預覽。

舊有單件出售、保守安全整理及預設關閉的新掉落安全自動出售保持原規則。新功能不擴大自動出售範圍，也不是無限背包或離線收益。沒有新增持久欄位，v0.11 存檔仍按原樣載入。

## v0.25 背包工作台

部位、武器路線與投資狀態共同決定目前可見清單；它們不改變已選出售的 ID。狀態列精確計算篩選外的選取，完整預覽仍列出每件並標示篩選外項目。清除篩選不是清空選取，也不是出售；確認仍必須核對完整清單。見 INVENTORY-WORKBENCH-GUIDE.md。
