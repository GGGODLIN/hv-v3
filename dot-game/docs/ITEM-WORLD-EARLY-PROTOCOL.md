# Predeclared exploratory early/low-investment cohort

Declared 2026-10-26 19:51 UTC before this cohort ran. The original `baseline` evidence remains unchanged. This protocol was proposed after the first cohort's all-win result, so it is **exploratory**, not a hidden replacement or preregistered original sample.

- Fresh seeds 1–100, with every profile retained. No forced RNG search.
- Ordinary stage1 only, retain the three original starter items through acquisition, buy no abilities and make no tactical changes. Use actual public `act` and `advance` operations; no hero, resource, stat, item, enemy, or RNG assignment.
- After at least ten actual normal clears/100 earned fragments, bind the first naturally dropped supported Fair/Average/Superior axe, rapier or club by numeric loot ID. If absent, continue stage1 up to40 attempts. Keep missing, blocked, censored, or failed profiles in the result. Retain all drops/starters; no selling or commissioning.
- Canonically clone the earned bound state using `validateSave(structuredClone(state))` for two arms: (1) original starter gear, target in backpack; (2) equip only the bound target, retaining starter armor/accessory. Equip via public `act` only.
- The same previously fixed IW strength5/five rounds/seed cost remains unchanged. Each arm receives one entry; only defeat permits one immediate paid retry from its naturally progressed state, without gear/ability changes. No retries after wins. Per encounter limit remains400 simulated seconds.
- Record losses and retries, growth with zero displayed deltas, entry/exit resources, all drops and ordinary-reward isolation exactly as for the original cohort. If every profile still wins, report that honestly; do not alter difficulty or search for a losing seed.
- Also measure the unchanged ordinary v0.23 advanced profile with already-equipped bound `loot-12` as target, after one normal clear earns its first migrated seed. Preserve the earlier `loot-1` backpack result separately; no advanced build changes.

This cohort represents deliberately uninvested legal choices, not random player behavior. It is source simulation and cannot establish browser/interruption correctness or universal balance.
