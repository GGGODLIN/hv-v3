這是 **Node 引擎實玩＋完整 UI 控制器的模擬 DOM**，不是實際瀏覽器、Tab／Enter 按鍵事件、視覺焦點框或捲動位置的驗收。沒有操作候選網站、正式網站或個人瀏覽器存檔。正式已驗收版本仍為 v0.25，既有發布工具阻擋未變。

## 固定範圍，不另找有利樣本

使用 v0.28 已知的 seed42 自然溢出重現，不把它包裝成新的隨機樣本或掉落頻率估計。從新角色的第1路線、均衡與預設設定開始，最多315次遠征，每場最多1,000個1秒 pulse；首次有待領掉落即停止。保留戰敗、截斷或界線內沒有溢出的結果，不延長或更換種子。

沿用原重現程序：前10場出發前，依現有屬性分數選各部位最高的已取得裝備，同分取較後項；其後不再換裝。每場出發前，逐件明確出售最早未鎖定的背包物品直到最多115件，並請求「通關後回營」。這是來源測量程序，不是新增到遊戲的自動選裝／出售政策。沒有 AP、藥水、委託、綁定、裝備界、資源或亂數注入。

每次公開動作與每個 pulse 後，都與 exact v0.29 commit `eb134eaf7da676c2834eb5c08bf84cb957e523b4` 的引擎比較完整狀態與所有遠征報告。**不排除欄位、不正規化訊息。**引擎、掉落與 session 三檔也必須保持該版本的相同 SHA256。

## 焦點重播

在相同已取得進度上，分別載入 exact v0.29 和本次 UI 原碼。選背包第1／中間／最後項、已穿的武器／護甲／飾品、自然待領物品，共7個確切 ID。每個先確實取得焦點，再呼叫原 click handler，重複3次；每次後再強制重繪一次。

模擬 DOM 會追蹤實際 HTML 祖先與連接狀態，替換子節點時把被移除節點的焦點退回 body，拒絕對隱藏、停用或脫離樹的節點聚焦。不是只記錄一個任意的 `activeElement` 指標，因此能重現原本被較簡略 mock 隱藏的問題。

| 來源 | 啟用比較後保留確切焦點 | 再次強制重繪後保留確切焦點 |
| --- | ---: | ---: |
| exact v0.29 | 3／21 | 3／21 |
| 本次修正 | 21／21 | 21／21 |

舊版的3次成功都是待領卡片：它原本就有局部焦點還原，這次只是維持其行為，不能把全部三種清單都說成先前失敗。背包及已穿裝備的18次操作均失去焦點；修正後都回到同一 ID 的新節點，而非舊的脫離節點或同名裝備。

兩個版本各21次比較與21次強制重繪，全程完整遊戲狀態（含 RNG）、控制器 dispatch 紀錄、storage write 紀錄都不變。這是只讀比較的證據，不代表實際瀏覽器焦點、滑鼠與鍵盤平台行為已驗收。移位／移除、篩選、匯入、領取、出售、戰鬥、唯讀與不搶其他控制項焦點等邊界另由來源 UI／獨立稽核測試覆蓋。

## 重現

先取回上述 exact commit 的完整 `dot-game/` 到另一目錄，再執行：

```sh
cd dot-game
node scripts/measure-comparison-focus.mjs \
  --baseline /path/to/exact-v029/dot-game \
  --output /path/to/new-comparison-focus.json
```

腳本驗證舊版四項執行檔及 HTML 雜湊，舊版重播也使用該版本原始 HTML；本次 engine／loot／session 必須相同。所有輸入（包含 UI、HTML、模擬 DOM 與腳本）在執行前後必須不變，輸出禁止覆寫既有檔案。正式收據在 [`measurements/comparison-focus.json`](measurements/comparison-focus.json)，包含每個 ID 的三次結果、同名持有物件數及前後狀態摘要。獨立重跑是否逐位元相同，以本次稽核文件與外部驗證收據為準，不由本文件預先宣稱。

這次沒有速度、勝率、難度或配裝最佳化的測量主張，也沒有新增原版 HV 規則。
