# 待領戰利品：先比較，再整理

v0.28 來源候選；尚未瀏覽器驗收或發布。正式版仍為已驗收 v0.25。這是既有溢出保護的介面與恢復操作，不是新的倉庫、掉落規則或原版 HV 機制。

## 背包滿了，東西沒有消失

背包仍限 120 件；出戰仍需沒有待領品，且保留至少 5 格。單次遠征可能超過預留量，既有引擎會保留溢出掉落。新待領區顯示取得順序、件數、背包空位，以及領完並保留出戰空間總共還需整理幾件。

待領區不受背包部位、武器路線、投入狀態或排序篩選影響；背包符合件數仍不包含待領品。點待領卡片能先看名稱、ID、品質、等級、武器特效與目前同部位的屬性比較，不必盲目賣掉別件後才知道得到了什麼。評分不是 DPS，也不代表跨路線最佳裝備。

**待領裝備只能查看比較。** 領取前不能換裝、鎖定、出售、自選出售、靈魂綁定或挑戰裝備界。沒有自動選售、丟棄、優先保留高品質或自動換裝。

## 如何回到可以出戰

- 背包已滿時，先比較，然後自行選擇要整理的背包裝備。既有單件出售、安全整理與自選出售仍會依先進先出順序補入待領品；不會賣掉待領品本身。
- 營地有空位且仍有待領品時，可按「依序領入背包 N 件」。一次只填滿目前空位，從最早取得的一件開始，不得跳過；滿了便停止，剩下的仍保留。
- 領取不花費或增加金幣、碎片、種子，不重抽、不改 ID、屬性、鎖定、綁定錨點或 IW 資料，也不恢復 HP／MP。
- 領入背包不等於已留足出戰空間。請看出戰提示，直到沒有待領品且背包最多 115 件，才可出發。
- 正在比較的待領品若已領入，仍保留同一 ID 的詳情；若被目前背包篩選隱藏，詳情會明示。其他裝備不會被自動選取。
- 領取會取消已開啟的自選出售確認，但保留個人勾選，必須重新預覽。它不延用舊確認，也不新增出售 ID。

例如背包 120 件、待領 1 件：賣掉 1 件後，待領品自動補進去，背包還是 120 件；還需要整理 5 件才能出戰。不是領到物品就憑空多了空間。

## 可恢復狀態與安全界線

既有格式 3 存檔容許「有待領品但背包尚有空位」。此時不用為了觸發補入而多賣一件，直接在營地領取即可。這是支援存檔邊界的明確恢復途徑，不聲稱一般自然遊玩會產生這種卡住狀態。

戰鬥、戰敗及唯讀分頁仍可比較，但不能領取。實際操作會再核對當前空間與隊列；重複、過期、空隊列或滿背包的操作不會複製物品。無控制權時要先按既有方式接手，不能借領取繞過存檔保護。

資料格式、命名空間、掉落亂數、120 格容量、5 格出戰保留、待領匯入最多 8 件、116 把永久綁定上限及既有出售保護均不變。舊版可讀相同形狀的待領資料，但沒有新待領介面或領取按鈕；既有 Exquisite IW1 的舊讀者限制仍適用。
