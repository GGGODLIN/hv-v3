# 背包工作台：找武器與投資進度

背包多了之後，可以先縮小清單，再逐件比較、換裝或預覽投資；不必只靠評分從頭找起。這是本作的介面便利功能，不是原版 HV 機制，也不會替你選裝、綁定、挑戰或出售。

## 三種條件一起用

- **部位**：全部、武器、護甲、飾品，沿用原有分類。
- **武器路線**：全部、戰斧、刺劍、戰棍、未辨識武器。選定某條武器路線時只會列出武器；不憑名稱片段猜測未知裝備的路線。
- **投入狀態**：全部、未綁定裝備、已綁定・未升 IW、IW1 已完成。後三項彼此分開；「未綁定裝備」也包含未綁定的護甲、飾品。一般鎖定或配裝保護不等於靈魂綁定。

條件取**交集**：例如「護甲＋刺劍」沒有結果，不代表裝備不見了。畫面顯示符合件數與背包總數；已穿著裝備仍在旅者面板，不算入背包結果。排序只改顯示順序，不改物品身分或分類。

「清除背包篩選」會清除這三種條件，顯示完整背包；不清空自選出售、不刪物品，也不改排序。篩選只留在目前分頁，不寫入存檔；重新載入、匯入或接手進度後，三種條件都恢復為「全部」。匯入／接手仍依既有安全規則清除自選出售，不沿用舊進度的出售意圖。

## 篩掉不等於取消選取

已開啟詳情的裝備可以繼續查看；若它不符合目前條件，畫面會明確提示它在篩選外。

已勾選出售的物品也會保留。狀態列顯示多少已選物品暫時隱藏，出售預覽仍完整列出**所有已選 ID**，並標出篩選外的項目。請檢查完整清單後才確認；篩選、排序或重設都不代表出售同意。取消預覽不出售，確認前的鎖定、報價與控制權核對仍照原規則。

委託武器成功後，畫面會清除新增的路線／投資條件，切回武器與最新排序並顯示交付物，避免剛買的武器被舊篩選藏住。武器仍依既有規則鎖定放入背包，不自動裝備。

## 不改變的規則

篩選不是強弱評分，也不是安全出售判斷。綁定、IW1、品質、路線各有用途；高分或已投資不保證最適合目前戰鬥。

戰鬥、亂數、掉落、容量、價格、物品 ID／錨點與資料格式3都不變。Item World 仍只實作已綁定 Fair／Average／Superior 武器的首階 IW1；沒有開放後續階、鍛造或拆解。原版事實、研究模型與本作改編仍分開記在 [ORIGINAL-HV](ORIGINAL-HV.md)；實際測試與發布狀態以 [STATUS](STATUS.md) 為準。
