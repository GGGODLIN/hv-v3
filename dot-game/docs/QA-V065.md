# v065 raw equipment-stat sorting — source candidate

## Change and baseline

v064 only offered newest, score, level and quality sorting; none could put highest owned-backpack-item stat contribution first. v065 adds seven choices to the same sort control: owned gear attack, HP, defense, critical, evade, block and parry rating, descending. Every card displays the selected gear stat, including protected items. Existing filters still intersect; ties retain latest acquisition order, missing stats count as zero. Rates display as percent, parry as rating, consistent with the detail table. Sorting uses unrounded actual values even if displayed figures look equal.

These are **item attributes**, not the final hero panel, a swap delta, DPS or win-rate recommendation. The v055 equip preview remains the place to inspect real whole-build changes. No original-HV claim, stat formula, drop, price, engine, save format or RNG change. This is an independent interface convenience. Sort choice is transient, not saved or imported; new page begins newest-first. No inventory order mutation.
