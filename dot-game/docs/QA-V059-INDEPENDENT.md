## 覆蓋

1. 正負微小平面屬性／機率、低於呈現精度的機率、普通攻擊差、普通機率差、真正相等。
2. 委託列與既有 `statDeltaText` 一致，正／負樣式依原始差值，不另造另一套格式。
3. 微小數值 fixture 經 `validateSave` 載入，assert 保存精度原樣保留；這是合法可載入的既有小數欄位邊界案例，不聲稱自然掉落已實際產生該差值。
4. 缺少屬性顯示有限值／相等；NaN、Infinity、-Infinity 與非數字存檔屬性均由既有驗證拒絕，不進入比較。
5. 開啟、關閉、重開不改完整 state、RNG、寫入與 action 紀錄；報價相同、差值一致。
6. 確認仍依 quote 原價扣款、交付 exact quoted item，現穿裝備及 RNG 不改；重複確認不重買。
7. 唯讀或戰鬥時強制 handler 不開啟／購買；報價變動後確認取消，不扣款交付。
