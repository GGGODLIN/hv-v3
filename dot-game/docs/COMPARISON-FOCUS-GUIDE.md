# 比較裝備時，保留鍵盤焦點

v0.30 修正背包與已穿裝備的比較按鈕：原本按下後，重畫清單會移除正在操作的按鈕，鍵盤焦點掉回頁面。現在重畫後仍追蹤**同一個物品 ID**，不以名稱、清單位置或裝備欄位猜測。待領裝備原本就能保留同一待領 ID 的焦點，本次保留這項行為。

只有「目前真正有焦點的比較按鈕」被重建時才復原。若同一件物品移動位置，優先找可見的同 ID 比較按鈕；找不到時回到可見的部位篩選；若該控制不可見，才使用可見的設定按鈕，不改篩選、不自動選另一件裝備。只是已選取某件裝備，不代表可以把焦點從其他控制拉走。

篩選、排序、領取、選售、設定／匯入與原有確認流程保持既有操作焦點；自動戰鬥或唯讀更新不會因為曾選過裝備而搶走其他控制的焦點。原有領取成功／清除篩選的明確完成焦點仍保留。

本次不改物品、戰鬥、亂數、存檔、價格或權限，也不提供自動換裝／出售。這是本作介面修正，不是原版 HV 機制或全面無障礙改造。來源測試以會真正斷開舊節點的模擬 DOM 執行；**不是實際瀏覽器或鍵盤裝置驗收**。正式版仍為已驗收 v0.25，網站發布阻擋未解除。
