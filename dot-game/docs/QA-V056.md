# v056 來源驗收：清波成長與生命恢復

## 缺陷與邊界

seed1，正常createGame/start，再設XP為下一級差1、該波只剩1HP敵人：普通/技能/流血清波升級，舊版maxHP575→597，卻以舊cap裁回575。受傷100HP時升級恢復90，再清波舊版補57.5而非新上限59.7。這是確定性的結算順序缺陷，不是調高遊戲難度補償或新HV規則。

finishWave集中於擊殺獎勵後讀stats.maxHp；移除三路caller傳入的早期快照。既有10%恢復、末波勝利全恢復、擊殺/掉寶/經驗/亂數算法/裝備成長公式不變。生命不同可能影響後續治癒與戰況，不能宣稱與未修舊版全程相同。

## 測試

主回歸8項：普通/流血×滿血升級、受傷升級、不升級；尚有敵人不觸發清波恢復；末波只結算一次。獨立驗收16項通過，加入技能、反擊對照、合法綁定/換裝/裝備界入口與HP成長；相同測試對舊v055有9項失敗。完整測試數與syntax結果見CHECKPOINT.json。

既有歷史parity fixtures保留原bytes：測試載入時只在記憶體套用精確post-kill上限修正，仍逐pulse完整比較HP/RNG/reports；4項歷史byte audit用6個唯一anchor精確反轉本輪差異，不忽略任何欄位。原戰報測試期待舊575裁切改成597/100%最低血量。詳見helpers/wave-growth-baseline.mjs。
