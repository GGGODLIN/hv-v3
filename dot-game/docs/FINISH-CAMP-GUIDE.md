# 通關後回營（v0.18 候選版）

- 戰鬥途中按「通關後回營」：完成這一次四波遠征、領取正常通關獎勵後回營，不進入下一場。
- 已排定時再次按下取消：恢復原本自動連戰規則。「勝利後繼續推進」的設定不被改動。
- 通關後三秒休息期間按下：這場已結算，立即回營，不重複發獎。
- 「回營整備」仍是立即離開，不必等通關。戰敗照原本方式處理，不保證一定獲勝。
- 只允許目前可寫入的分頁操作；營地與戰敗時不可排定。使用原生按鈕，可用 Tab 聚焦、Enter／空白鍵觸發。
- 排定狀態只在本次頁面與角色物件存續；正常 Tick、切換面板不取消。回營、戰敗、讀檔、匯入、重新載入或接手／失去分頁所有權均清除，匯出存檔不包含這項意圖。

這是本作掛機便利設計，不是原版 HV 規則。戰鬥、掉落、隨機數、成長、價格和一般通關獎勵不變。未使用時維持既有自動連戰行為。

## 恢復與啟動

從備份 exact commit 取回整個 dot-game/，不只編譯產物。靜態 ES modules，沒有外部依賴或建置步驟。用 Node 20+ 執行 `node --test tests/*.test.mjs`；用 `python3 -m http.server 8000` 在 dot-game/ 啟動，瀏覽 `http://localhost:8000/`。原始碼、原創 SVG／CSS 與測試均在同一來源目錄；CHECKPOINT.json 記錄各有效負載檔案的 SHA-256。

候選來源通過測試不等於公開版或瀏覽器驗收通過；已接受的正式版仍是 v0.17。
