# 遠征戰報與比較基準（v0.9）

## 怎麼用
每次通關、戰敗或中途回營後，戰鬥控制區下方會保留最近兩次結果。開始下一場、自動連刷或換裝不會清除已結算戰報。按「設為比較基準」可把最近一場另外固定，之後自動重刷也不會擠掉它；再次按下則改用新的最近結果。

這些是本次分頁遊玩的觀察，不是永久成就或雲端歷史。引擎以 WeakMap 保存最多兩筆，UI 額外固定一筆分離副本，均不寫進存檔。重新整理、匯入或載入不同進度後清空；控制權同步也會清掉固定基準。舊存檔不需要升級版本，不會從外來 JSON 載入戰報。

## 數字意思
- 出發關卡、武器、戰術、等級與面板攻擊／生命上限／一般減傷是出發時快照，不隨後來換裝改寫。結束等級包含通關獎勵的成長。
- 秒數是遊戲實際處理的戰鬥時間，不包含營地、通關後休息或關閉頁面的時間。未完成的中途回營不能當成快速通關。
- 普攻、技能、流血傷害均計實際扣除敵人的生命。過量傷害不計入，不是畫面飄字的簡單總和。
- 承受生命損失是敵方傷害實際扣除的生命總量，不扣除治療；最低生命比例採各觀測時點當時的生命上限，並包含波次／成長造成的上限變化。
- 攻擊總數包含技能攻擊。治癒、藥水、耗魔另列，不代表額外攻擊回合。
- 特效次數是成功施加／刷新次數，不是層數、命中率或效果節省的傷害。流血在後續 Tick 扣除的生命另列。

本作沒有把破甲「額外造成多少傷害」或暈眩「避免多少傷害」當成已知數字，也不換算 DPS 或替你宣布最佳武器。不同關卡、等級、裝備、戰術與隨機骰都會影響結果；同一關的兩次實戰也不等於受控實驗。用報告發現想再試的配裝，而不是把單場差異全歸因於武器。

## 正確性與範圍
所有紀錄都是旁路觀察，既有傷害鏈、亂數消耗、掉寶、獎勵、時序與存檔內容不應改變。通關在原有獎勵後、補滿前結算；失敗在原有收尾前結算；手動撤退只結算尚未結束的戰鬥。通關休息時回營、失敗後回營或重複按鈕不會把已完成結果改成撤退。

測試涵蓋過量傷害、致命流血、暈眩恢復攻擊、特效刷新、一次性結算、快照不可回寫、失敗／中止／勝利、清除匯入資料，以及與已驗收 v0.8.1 的自然養成逐步完整狀態／RNG 對照。完整數量、來源及限制見 ACCEPTANCE-V09.md。舊來源位元組凍結檢查保留原值並明確改為歷史 fixture；目前遊戲行為則由直接對照驗證，不偷偷更新舊黃金數值。
