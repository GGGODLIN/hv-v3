## 目的／邊界
配裝測試或想收一輪掉寶時，可在出發前就選擇通關後回營，不必在短戰鬥中搶按。這是本作 idle UX 適配；沒有新增原版事實、數值模型、資源、存檔欄位或自動消費。舊「開始遠征」改標「連續遠征」，行為不變；新原生按鈕「單次遠征」附完整四波說明。

## 實作
`startOnce` 只接受營地普通遠征，呼叫既有 start 成功後才加入既有 WeakSet 排程。滿背包／待領拒絕不留旗標；battle／defeat／Item World 不新開。排程沿用勝利完整結算後回營、取消、敗北／撤退／匯入／接手清除。UI 仍使用同一 dispatch 所有權與 pump lifecycle，重複點擊不重置計時。存檔仍 v3，不保存單次選項。
