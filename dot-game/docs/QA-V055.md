# v055 來源驗收：角色面板換裝預覽

## 實作與依據
使用既有 stats(state) 對目前配裝及只替換同slot的淺層equipment-map投影計算。來源資料皆由既有遊戲載入／驗證建立；投影只讀，不走 equip/recover/act。沒有新增HV公式或材料。生命上限／ADB使用數值差，減傷及機率使用百分點差；細小變化仍保留方向，零差明示相同。原始詞綴表與武器路線說明保留。

## 測試
主要測試 tests/loadout-preview.test.mjs：8項。獨立測試 tests/loadout-preview-audit.test.mjs：12項，實際 clone→act(equip) 結果為oracle。兩者均通過。完整套件與四個runtime語法檢查的最終結果見 CHECKPOINT.json。

獨立QA指出兩個問題並修正：普通重繪需將熟練度／能力／屬性加入快取依據；敗北狀態既有規則允許換裝，新提示不應誤稱必須先回營。沒有為了提示改動戰鬥或換裝規則。

原先4個歷史frozen-byte檢查因本輪UI/CSS修改失敗，加入精確變更逆轉 helper（tests/helpers/loadout-preview-baseline.mjs），原始hash斷言不變。版本文字斷言精確更新至v0.55來源候選。首輪混入尚未完成的獨立測試，不是最終驗收；最終全量會重新執行。

## 尚未驗收
DOM harness 不等於瀏覽器。候選的真實畫面、窄欄換行、鍵盤／輔助技術、正常遊玩與正式存檔互不污染，需發布隔離候選後檢查；本文件不宣稱已發布。現有正式v054維持不動。
