## 覆蓋

1. 新營地與第一波為 0 / 4。
2. 自然通過第一至第四波時，只計已完成波數。
3. 自然勝利及倒數期間為 4 / 4。
4. 自動重刷下一場回到 0 / 4。
5. 勝利倒數中撤退回營為 0 / 4。
6. 唯讀分頁同樣顯示完成，不寫存檔。
7. 敗北保留既有已完成進度，不宣稱末波勝利。
8. 合成七波邊界用實際 totalWaves，不硬編碼四波。
9. 正常「打完回營」首勝後為營地 0 / 4，之後 advance 不再開戰。
10. fight 時敵人陣列空白本身不構成勝利。

每次重繪逐位元組核對完整 game JSON（含 RNG、獎勵、時間與物品），同時核對 session 戰報 JSON、action calls 與 storage writes 都不變。修正只讀 `mode` 與 `_phase`，不改原版 HV 規則或本作任何戰鬥／獎勵機制。
