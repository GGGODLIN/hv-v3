# Predeclared natural-play source measurement protocol

Frozen 2026-10-26 19:46 UTC before any cohort outcome was measured. This is deterministic source simulation, not browser evidence or a population balance estimate.

- Fresh profiles: `createGame(seed)` for seeds 1–100, no cherry-picking or omitted acquisition failures.
- Acquisition: normal route `min(unlocked, 5)`, falling back one route after each defeat. Equip highest `scoreItem` held item per slot through `act('equip')`; score ties preserve held ordering. Learn/slot rank-one HP Tank, MP Tank, One-Handed Damage in that order as AP permits; no upgrades. Balanced strategy/front targeting/default protection. Automatic battle logic only, no manual resource intervention.
- Stop acquisition at the first camp state with at least ten normal wins/100 naturally earned fragments and a naturally dropped supported Fair/Average/Superior axe, rapier or club. Target is the first such acquired item by numeric loot ID, never a generated/commissioned replacement. Bind once through the full public quote/action. Retain all starter equipment and all drops; no selling. Maximum 40 acquisition attempts, 400 simulated seconds per encounter; a blocked/censored profile stays in the output.
- **Fixed local IW strength stage 5.** The earlier `ceil(entryLevel/3)` design was rejected architecturally before measurements because its exponential local scaling punished leveling. This is not an outcome-driven retune. Five rounds and damage multipliers 1.00/1.02/1.04/1.06/1.08 are fixed before execution.
- Four IW arms from each same naturally earned bound profile, cloned only with `validateSave(structuredClone(profile))`: score-best versus original-starter armor/accessory/weapon policy, crossed with target equipped versus target in backpack. The equipped-target arm overrides weapon choice; backpack arms exclude the target from weapon selection. Gear changes exclusively use public `act`; no direct item, resource, hero, RNG, save or enemy mutation.
- Each arm spends one earned seed for its first entry. Only a defeat receives one immediate paid retry, from its naturally progressed post-defeat state, without gear/ability retuning. A win is never retried. No other recovery/reroll policy is introduced.
- Record complete acquisition runs, first and retry outcomes, elapsed time, HP loss, levels, held/drop counts, seed balances, target/gear identity and stats, predicted/display-rounded neutral stat fields, actual final target changes and stable ordinary reward counters. Check IW kill gold/XP ledgers and absence of ordinary win/unlock/clear-time/fragment/seed-completion rewards.
- Optional advanced profile: read an unchanged ordinary v0.23 save via an explicit CLI path, canonically migrate with `validateSave`, make no build changes, earn one seed via one normal clear at its selected route, and trial an already bound supported weapon. No private export is copied into the source tree. Report this separately, never merge it into the fresh cohort.
- Record source/script hashes before and after execution. Keep failures, neutral cases and bounded/censored cases. No outcome-driven tuning; any necessary measurement-script correction must be identified, with old result files retained when produced.

The starter arms are deliberately weaker held-gear choices, not random naturally occurring player choices. Score omits proc value and is not DPS. Paired clones share initial durable state/RNG but their combat draw sequences can diverge; differences do not isolate one exact causal mechanic.
