# Independent dot game v0.1 module contract
Native ES modules, no runtime dependencies, static browser serving.
engine.js exports createGame(seed=1), advance(state, seconds), act(state, action, payload), stats(state), validateSave(input).
State is plain JSON. createGame returns state; advance and act mutate same state and return it. validateSave returns sanitized state or throws. stats returns derived {maxHp,maxMp,attack,defense,crit,evade,block}.
State public fields: version:1, seed:number, hero:{level,xp,xpNext,hp,mp,gold}, mode:'town'|'battle'|'defeat', stage:number (selected), unlocked:number, wave:number, totalWaves:number, kills:number, wins:number, autoAdvance:boolean, inventory:Item[], equipment:{weapon:Item,armor:Item,accessory:Item}, enemies:Enemy[], events:Event[], logs:string[], battle:{elapsed:number,cleared:number,bestTimes:{[stage]:number}}.
Item {id,name,slot:'weapon'|'armor'|'accessory',quality,rarityColor,level,roll,power,stats:{attack?,defense?,hp?,crit?,evade?,block?},locked:boolean,description:string}.
Enemy {id,name,hp,maxHp,attack,defense,boss:boolean}. Event {id,type:'hit'|'miss'|'crit'|'block'|'loot'|'level'|'win'|'defeat'|'heal',text,value?,target?:string}. Bound events array latest 30, logs latest 30. State has no timestamps from wall clock needed for offline progression.
Actions: 'start' (selected stage), 'retreat', 'selectStage' (integer payload), 'equip' (item id string), 'sell' (item id), 'lock' (item id), 'sellCommon' (only unlocked non-equipped weakest tiers), 'setAutoAdvance' (boolean), 'heal' (optional resource action). Invalid actions must leave valid state, never crash UI. Start fresh run from town; defeat returns recovery via retreat. State equip replaces slot and keeps old item in inventory. UI can read additional documented fields, coordinate additions.
Loot module exports generateItem(rng, level, slot?), describeItem(item), scoreItem(item), qualityFromRoll(roll), rarity tables. rng is function returning [0,1). All random generation deterministic via engine seed PRNG passed to loot. Equip generation pure. No existing game implementation/dataset/art reused.
UI owns persistence wrapper localStorage and export/import. Versioned validated save. No offline progression. Save must not run multiple background simulations; pause when document hidden, resume with capped dt. Engine advance caps catch-up to 2sec; UI at 10–20Hz. Seeded node tests required.
