# 委託後綴選擇 — v0.18

## 怎麼玩
先完成一次遠征，回營後點「配裝」。三種武器各自有「委託後綴」選單；預設屠戮。選擇後再按預覽，查看實際名稱、等級、七項屬性、目前武器比較、價格與剩餘金幣。確認才付費交貨；取消不花錢。新武器鎖定放入背包，必須自行選擇裝備；原裝備與方案不會被替換。

本作目前支援戰斧屠戮；戰棍屠戮／平衡；刺劍屠戮／平衡／靈巧。這不是原版全部合法組合。屠戮偏向直接攻擊，平衡用較低攻擊換暴擊，靈巧用較低攻擊換招架值。招架值不是直接百分比；沿用既有單次判定率適配，可能增加反擊資格但不保證更快。別只看評分或一次戰報。

## 原版、模型、本作適配
合法性與既有端點來自固定原版研究003；詳細行號及未支援 Axe Balance／Club Nimble 見 ACCEPTANCE-V018.md。沒有新增原版未考證詞綴、掉落權重或數值。品質 `(R/200)^1.52` 是既有研究模型，不宣稱伺服器精確。付費確定性委託不是原版 Bazaar：沿用優良 Superior、全部 R110、無前綴、當前角色等級、`max(250, 4 × saleValue)` 金幣公式，仍可刷到更高品質與前綴裝備。不同後綴因既有物品估價而有不同價格，公式未改。

## 安全與恢復
預覽不取 RNG、不改資源。確認綁定家族、後綴、完整物品、價格、金幣、角色等級、裝備／背包 ID 和計數；任何相關變更使舊報價失效，不會偷偷購買替代品。選單只是本分頁暫時選擇，重整回到屠戮；已買物品正常存檔，沿用 v3 schema。舊 Slaughter 呼叫仍有效，舊未完成報價會安全失效。

啟動仍為 `cd dot-game && python3 -m http.server 8000`，開啟 localhost:8000；測試 `npm test`（Node 內建測試器，無套件安裝或編譯需求）。完整原始碼、獨立 SVG/canvas 素材、歷史測試與建置說明都在 dot-game；精確已驗證版本以 STATUS.md 與該 commit 的備份驗證紀錄 為準，候選不等於已驗收。瀏覽器存檔請另行由「存檔→匯出存檔」保管。
