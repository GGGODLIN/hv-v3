# 出發配置戰報 — v0.22

這是本作觀察工具，不是原版 HV 新數值規則或配裝評分器。

按開始遠征時只擷取一次真實配置。最近兩次戰報與手動基準保留出發快照；回營換裝、改集火策略或能力，不改寫過去。

- 保留出發層數／等級、戰術、武器及攻擊／生命／一般減傷。
- 新增集火政策與自動 Protection 開關。ON 只是允許自動施放，不代表已生效、曾施放或全程覆蓋；實際施放次數與減免量另列。
- 展開出發配置看實際 Major 槽的能力 ID、名稱與 Rank。已學未啟用者不列為啟用。
- 實際三件裝備保留 ID、名稱、等級、品質，不拿最近套用的 A/B/C 方案代替。相同名稱仍可能是不同裝備，ID 可區分。

不是完整角色複製：沒有全量詞綴、熟練度、逐回合歷史。層數、等級、配裝、政策與 RNG 都可影響勝負；同關兩次不能推論某配置必然較好。缺失欄位顯示未知，不以現在狀態補填過去。

## 保存界線

只在本次分頁工作階段保留兩份戰報及一份手動固定基準。重新整理、匯入、載入或進度控制權變更清空；不寫入玩家存檔。它不是長期歷史或備份。

`report.build` 包含 `targetPriority`、`autoProtection`、最多五個 `{id,rank}` 能力及三個 `{slot,id,name,level,quality}` 裝備摘要。內部凍結，讀取提供深層分離副本。不消耗 RNG，不改傷害、反擊、流血、魔法、成長、掉落或存檔格式。
