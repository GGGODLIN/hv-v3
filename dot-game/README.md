## 怎麼玩

1. 選路線出征，自動攻擊與施放技能。可立即回營，或按「通關後回營」完整領獎再停止連戰。
2. 比較掉落、換裝、鎖定與自行選取出售。v0.28可先查看滿背包的待領裝備，再決定如何騰出空間；有空位時可於營地按順序領入。v0.25新增本次分頁的武器路線／投資狀態篩選、背包符合數與清除篩選；隱藏選取仍完整列入出售確認，不會替你選裝或賣裝。營地有三組配裝記錄及先預覽確切費用的武器委託；武器特效不同，不只看分數。
3. 用「戰況／配裝／成長」分頁找工具。AP先學習再裝入能力槽；戰術、集火與預設關閉的Protection各有取捨。v0.27可在營地選擇預設關閉的「額外緊急補給」：只補充均衡／猛攻，治癒後HP仍低於30%才自動用現有藥水，保留1瓶手動。持久原本的自動喝藥仍獨立運作，可用最後1瓶。
4. 正常通關固定獲得**10靈魂碎片＋1世界之種**，不補發歷史獎勵。這是本作節奏改編，不是原版掉率。
5. 明確確認後，可按品質花100／250／500／1000碎片綁定已擁有的戰斧／刺劍／戰棍。保留原始ID、骰值與詞綴，武器隨角色等級成長；不自動選擇或花費。
6. 已綁定的**尚可／普通／優良／精良（Fair／Average／Superior／Exquisite）武器**可預覽並花1種子挑戰五回合裝備界。固定本作強度5，並非原版Lv100／Hard；勝利使同一件武器永久IW1，結束必回營，不自動重刷或扣第二顆種子。

試煉可選已穿著或背包武器，不自動換裝。戰敗、撤退、重載不退種子是本作適配；已結算的擊殺收益保留，未通關不升IW。只實作首階；原版Fair／Average／Superior最高IW10、Exquisite最高IW15，後續階與其他品質未實作，不代表原版不合法。取整可能讓某個顯示屬性不變，預覽顯示真實結果。

綁定武器不能解除、解鎖或出售，總持有保護上限116把。未實作鍛造、拆解、CP、原版Charm獎勵或種子商店。見[靈魂綁定](docs/SOULBIND-GUIDE.md)、[裝備界規則與限制](docs/ITEM-WORLD-GUIDE.md)。

## 啟動與測試

完整取回`dot-game/`，不需安裝依賴或建置。需Python3；測試需Node20以上。

```sh
cd dot-game
python3 -m http.server 8000
node --test tests/*.test.mjs
```

不要以file://直接開ES modules。進度存在瀏覽器本機；清除網站資料前，先用遊戲內「匯出存檔」。

## v0.28 看清待領裝備，再決定如何整理

背包滿時保留的待領裝備，現在有獨立清單與現穿裝備比較，不再只有無法出戰的數字提示。清單保持掉落先後順序，不受背包篩選與排序影響；待領區不是額外可裝備的背包。領入前不能出售、鎖定、換裝、綁定或進入裝備界。

營地有空位時，可按「領入背包」只領入目前放得下的前幾件；不扣錢、不抽裝、不新增獎勵。原有出售後自動依序補入的行為仍在。背包仍上限120件，待領未清或空位不足5格仍不能出戰；沒有擴倉或改動掉落率。116把永久綁定武器的保護上限沒有問題，本次不改它。

自然來源實玩能產生滿背包溢出；有效匯入存檔也可原本就有空位與待領裝備。這兩種情境分開驗證，不把匯入邊界案例稱為自然遊玩死鎖。見[待領指南](docs/PENDING-LOOT-GUIDE.md)、[來源驗收](docs/ACCEPTANCE-V028.md)、[實玩測量](docs/PENDING-LOOT-MEASUREMENTS.md)。本次仍只做來源開發／備份，沿用下列發布阻擋。
