## 怎麼玩

1. 選路線出征，自動攻擊與施放技能。可立即回營，或按「通關後回營」完整領獎再停止連戰。
2. 比較掉落、換裝、鎖定與自行選取出售。v0.25新增本次分頁的武器路線／投資狀態篩選、背包符合數與清除篩選；隱藏選取仍完整列入出售確認，不會替你選裝或賣裝。營地有三組配裝記錄及先預覽確切費用的武器委託；武器特效不同，不只看分數。
3. 用「戰況／配裝／成長」分頁找工具。AP先學習再裝入能力槽；戰術、集火與預設關閉的Protection各有取捨。
4. 正常通關固定獲得**10靈魂碎片＋1世界之種**，不補發歷史獎勵。這是本作節奏改編，不是原版掉率。
5. 明確確認後，可按品質花100／250／500／1000碎片綁定已擁有的戰斧／刺劍／戰棍。保留原始ID、骰值與詞綴，武器隨角色等級成長；不自動選擇或花費。
6. 已綁定的**尚可／普通／優良（Fair／Average／Superior）武器**可預覽並花1種子挑戰五回合裝備界。固定本作強度5，並非原版Lv100／Hard；勝利使同一件武器永久IW1，結束必回營，不自動重刷或扣第二顆種子。

試煉可選已穿著或背包武器，不自動換裝。戰敗、撤退、重載不退種子是本作適配；已結算的擊殺收益保留，未通關不升IW。只實作首階；原版上述品質最高IW10，後續階與其他品質未實作，不代表原版不合法。取整可能讓某個顯示屬性不變，預覽顯示真實結果。

綁定武器不能解除、解鎖或出售，總持有保護上限116把。未實作鍛造、拆解、CP、原版Charm獎勵或種子商店。見[靈魂綁定](docs/SOULBIND-GUIDE.md)、[裝備界規則與限制](docs/ITEM-WORLD-GUIDE.md)。

## 啟動與測試

完整取回`dot-game/`，不需安裝依賴或建置。需Python3；測試需Node20以上。

```sh
cd dot-game
python3 -m http.server 8000
node --test tests/*.test.mjs
```

不要以file://直接開ES modules。進度存在瀏覽器本機；清除網站資料前，先用遊戲內「匯出存檔」。
