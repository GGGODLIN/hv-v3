Isekai Mode

From EHWiki
Jump to navigationJump to search

Isekai Mode allows you to start from scratch in HentaiVerse. At the beginning of a season, you start at level 0 without any equipment. There is a separate currency, ISK. Moogle attachements is only possible if you are a donator. Isekai mode has been introduced since Hentaiverse version 0.87.


Isekai is accessed through the mode selector found on the top right of the screen.
