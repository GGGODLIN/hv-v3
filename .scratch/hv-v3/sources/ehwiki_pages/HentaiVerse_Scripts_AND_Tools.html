Intro

  • Browsers may require script managing plugins.
    • Firefox: Tampermonkey.
    • Chrome: Tampermonkey. Alternatively go to Tools -> Extension and drop the script directly into that screen (chrome://extensions).
    • Opera: Violentmonkey.

Please do not PM the producers of these scripts for updates, especially after HV patch releases.

  • For the best performance and full compatibility in Hentaiverse, use the Custom Font Engine (Hentaiverse Menu: Character -> Settings).

Making Scripts & Tools

Players are free to make new scripts for purposes such as making modifications and additions to the UI or changing key mappings and controls in general.

Forbidden Actions

Any script used to do ANY of the following inside the HentaiVerse is strictly forbidden. Offenders will be banned.

  • Any automation or semi-automation of gameplay beyond a single round of battle.
    • Automation within a single battle round is allowed, but must stop after each round and requires player input to proceed. This can be done by either clicking the end of round popup manually to proceed, or having the script disabled until resumed by the player at the start of the following round.
  • Solving of the riddlemaster by scripts or tools.
  • Anything that uses multi-threading (multiple connections), both in battle and out-of-battle.
  • Any automation that gives player advantage outside of battle.
