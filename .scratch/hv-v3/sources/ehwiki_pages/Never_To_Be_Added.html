Never To Be Added

From EHWiki
Jump to navigationJump to search

The following is a list of requested features or changes that will never be made in E-Hentai or its related systems in the foreseeable future. Please do not request them. This list is not comprehensive and is subject to change.

E-Hentai

  • Support for Internet Explorer[1][2][3]
  • Changes to the pre-2013 awards[4]
  • Archived bounties[5]
  • Usage of Usenet or Discord in any way[IRC]
  • A name change Hath Perk[PM]

Donations

  • Any use of PayPal[6][7][8][9][10][11]
  • Formal acceptance of other crypto-currencies[12]

E-Hentai Galleries

  • 3D, Artist, or Manhwa categories[PM][13]
  • Systematized linking of different versions of the same gallery; e.g. different translations[14]
  • Sorting galleries beyond the default of descending published date[IRC]
  • Support for Unicode filenames[15]
  • Gallery annotations[16]
  • Voting on comments in a gallery where the user has already made a comment[17]
  • Alpha transparency removal[18]
  • Switching to SHA-256 hashes[IRC]
  • Publishing DMCA request list[19]

Searching

  • Options involving favorites[20][21]
  • Exact tag searches simultaneously with additional terms without including longer string searches of said tag[22]

Tagging

  • Certain tags
  • A complete listing of all tagging actions made on the galleries (a la the Boorus)[PM]
  • Unicode support[PM]
  • Sorting tags by date added[23]
  • Power display on tags[24]
  • A means to search for tags based on their mod power (beyond searching for weak tags with the weak: qualifier)[IRC]
  • Searching with namespaces alone[25]
  • Distinguishing tags that share the same name and namespace[26]
  • Pre-tagging galleries (before publishing)[27]

Uploading

  • .7z files[28]
  • .Bmp/.Tif files[29]
  • Gallery already exists warning[PM]

EHTracker

  • Any indication whether a user has added a torrent to their own gallery or if another user has (or if both are true)[IRC]
  • Ownerless torrents or ones made directly from the archive server[30]
  • Rewards for torrent seeding (besides one's own torrents)[31]

H@H

  • UPnP[32]
  • Using hostnames[33]
  • Custom domains[34]

HentaiVerse

  • Almost any change involving Stamina
    • Any changes or means to avoid the RiddleMaster or its consequences[35][36]
  • Void spells or resistance for players[37]
  • Removal of Ring of Blood's daily cooldown[38]

Items

  • Items with charges[PM]

Equipment

  • Being able to enter the Item World on equipment that is being actively worn[39]
  • A means to undo soulfusion[IRC]
  • An equipment auction house[40]
