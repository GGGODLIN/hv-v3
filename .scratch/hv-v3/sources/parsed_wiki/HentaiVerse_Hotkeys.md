| Hotkey | Function | Notes |

| [cs=3]During Combat |

| F1 - F12 | Use Item | • Use items in slots 1-12, where F1 corresponds to Item Slot 1. • Slots 13-15 currently have no hotkeys. |

| ⇧Shift + F1 - F6 | Use Scroll | Use a Scroll in a Scroll Slot, where F1 corresponds to Scroll Slot 1. |

| Ctrl + F1 - F6 | Use Infusion | Use an Infusion in an Infusion Slot, where F1 corresponds to Infusion Slot 1. |

| 1 - 0 | Target Monster | • 1 corresponds to Monster A and 0 to Monster J. • Default behavior is Attack. • Both the regular number keys and numpad keys will work. |

| Alt + 1 - 0 | Cast Quickbar Spell | 1 corresponds to the spell in Quickbar Slot 1 and 0 to Slot 10. |

| Q | Select Attack command |  |

| W | Select Skillbook command | Repeated presses will toggle between the Skills and Spells panes. |

| E | Select Items command |  |

| R | Repeat last action | Will attempt to repeat the previously used action. Attempting an invalid action (i.e. using an item that is on cooldown) will still advance a turn. |

| S | Toggle Spirit Stance |  |

| D | Use Defend command |  |

| F | Use Focus command |  |

| G (or P) | Use Powerup Gem | Will open the items menu before trying to use the powerup gem. |

| Spacebar (or (Enter↵/Return) | Advance Round | Pressing it at the end of a battle series will return the player to that battle mode's default screen. |

| [cs=3]In The Armory |

| C | Launch Equipment popup | • Mouse over a piece of equipment to use. • Popups must be enabled. • Does not work if Caps Lock is on. |

| X | Navigate to equipment's Modify page | • Will navigate to the page of the last piece of equipment the mouse has hovered over. • Does not work if Caps Lock is on. • Does not work in the shop. |

| Spacebar (or (Enter↵/Return) | Confirm | Pressing it will click the confirm button if available. |

| Esc | Close confirmation box | Closes it without confirming the action. |

## Troubleshooting

If a hotkey isn't working for you, consider the following:

Make sure the action is valid.
For example trying to use the infusion hotkey for an infusion slot you haven't unlocked or an infusion that is on cooldown will do nothing.

- Make sure no other program is intercepting the hotkey.

- Holding down either of ⇧Shift or Alt in The Armory will disable hotkeys.

- Make sure your keyboard isn't broken.
